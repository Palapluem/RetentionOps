- เชื่อม GitHub repo เดิมซึ่งมีเพียง README โดยรักษา initial commit `d49a163` และสร้าง
  branch `chore/rop-001-project-foundation`; ไม่แก้โค้ดบน main

  และ immutable local source releases
- `training.py`, `pipeline.py`: train-only preprocessing, fixed Logistic Regression เทียบ
  constant prior, temporal train/validation/test, reproducibility identity และ model checksum
- `storage.py`, `api.py`: atomic publication, active-release isolation, typed bounded API,
  readiness และ read-only SQL; `dashboard.html` แสดงค่าจาก API จริง

  guidance, dependency lock พร้อม hash, Docker/Compose และ CI/issue/PR templates

## ผลโมเดลที่ตีความได้อย่างจำกัด

ข้อมูลจำลอง seed 342, test cutoff 2026-09-30, freeze 2026-11-03:
average precision ประมาณ 0.462 เทียบ constant prior 0.114; ROC-AUC 0.831;
Brier 0.081; Recall@10% 0.378 โดยเลือก 65 จาก 650 แถว
เป็นคะแนน synthetic เท่านั้น ไม่ใช่หลักฐานผลลูกค้าจริงหรือ uplift ของแคมเปญ
